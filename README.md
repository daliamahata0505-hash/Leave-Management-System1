# Leave Management System

## Minor Project 6

A web-based Leave Management System developed using Appsmith, PostgreSQL, Docker, and AWS EC2.

## Technologies Used

- Appsmith – Frontend and application interface
- PostgreSQL – Database
- Docker – Containerization
- AWS EC2 – Cloud deployment
- GitHub – Project repository

## Project Features

- Employee leave application
- Leave request management
- Manager approval and rejection
- Leave status tracking
- Leave type display
- Start date and end date display
- Database-based leave records
- Approval and rejection actions
- Cloud deployment using AWS EC2

## System Workflow

1. Employee submits a leave request.
2. Leave details are stored in PostgreSQL.
3. Manager views the leave requests.
4. Manager can approve or reject a request.
5. The leave status is updated in the database.
6. Updated status is displayed in the Appsmith application.

## Project Architecture

Employee
↓
Appsmith Application
↓
PostgreSQL Database
↓
Docker
↓
AWS EC2

## Database

The system uses PostgreSQL to store leave request information such as:

- Employee Name
- Leave Type
- Start Date
- End Date
- Reason
- Status
